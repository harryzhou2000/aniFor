# aniFor

aniFor is a client-side, mobile-first particle sandbox. It uses a deterministic cellular simulation and a WebGL/Pixi renderer to make a small set of materials feel interactive without requiring a server, account, or database.

## Requirements

- Node.js `^20.19.0` or `>=22.12.0` (the Vite 8 dependency requirement)
- npm
- A WebGL-capable browser to run the sandbox
- Installed Google Chrome to run the configured E2E suite

## Install and run

```sh
npm ci
npm run dev
```

## Verify and build

```sh
npm test             # Vitest unit tests
npm run check        # TypeScript application typecheck
npm run check:test   # TypeScript application and test typecheck
npm run build        # production build to dist/
npm run test:e2e     # Playwright, configured to use installed Chrome
```

## Static deployment

Deploy the generated `dist/` directory to any static host. The app has no runtime server dependency.

Vite's base path comes from `VITE_BASE` and defaults to `/`. For a site served below a nested path, build with that path, including its trailing slash:

```sh
VITE_BASE=/nested/ npm run build
```

For example, publish that build at `https://example.com/nested/`. Do not hard-code root-relative asset paths in deployment glue.

## Current sandbox controls

- **Materials:** Wall, Sand, Water, and Fire
- **Erase:** clears cells under the brush
- **Smoke:** generated by fire; it is not a selectable tool
- **Brush:** adjustable from 1 to 12 cells
- **Timeline:** Pause/Play and Advance one step (while paused)
- **Recovery:** Clear stores one in-memory recovery point; Recover consumes it
- **Save / load:** opens file and save-code import/export controls

Drag with one pointer to paint. A second active pointer cancels painting and enters pinch/pan mode; neither pointer paints again until all gesture pointers are released. Press <kbd>Escape</kbd> to cancel an active stroke or gesture.

## Accessibility and interaction

The sandbox surface is focusable and labelled with usage instructions. Material and action controls are native buttons or a range input, expose their selected or paused state, and participate in keyboard tab order. Status changes are announced through a status region; focus indicators and reduced-motion styling are provided. `touch-action: none` is scoped to the game surface so surrounding browser controls retain normal browser interaction.

The current renderer requires WebGL. When WebGL is unavailable, the UI shows an unsupported-renderer state; there is no Canvas fallback.

## Persistence status

The sandbox keeps one best-effort autosave in local browser storage. It restores a valid autosave at startup. The app queues an autosave after every authoritative simulation advance and rendered action; one coalescing timer limits writes to at most one every 500 ms, including static ticks, running simulation, and painting. The pending save is cancelled during page unload, so closing a tab immediately after an action may not preserve that action.

If a stored save cannot be decoded or validated, the app starts normally and removes the corrupt stored value when browser storage permits. If browser storage is blocked, unavailable, or full, autosave quietly fails. A snapshot that passes decoding but is rejected by the running simulation is ignored at startup.

Open **Save / load** to:

- **Export file** or **Import file**. Export downloads `anifor-save.anif`; import accepts the same canonical save payload.
- Use the text export action to place a Base64 save code in the text area, then copy it yourself.
- Paste a code into the text area and use the text import action to load it.

Text input is limited to **512 KiB**; decoded binary data and imported files are limited to **256 KiB**. The uncompressed `ANIF` v1 payload includes a CRC-32 checksum and is validated for its ruleset, dimensions, lengths, material values, and lifetimes before an import replaces the current world. A successful import atomically stores the previous timeline in the same one-slot recovery point used by Clear; **Recover** can restore it once. A later clear or import replaces that recovery point.

Saves remain local unless you export them. There is no URL or browser-history sharing, compression, cloud sync, or general undo.
