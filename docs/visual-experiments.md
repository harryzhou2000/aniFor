# Visual experiments

This is a short index of earlier rendering experiments. Their detailed measurements and review notes are available in Git history. They do not define current visual acceptance criteria.

- Reconstructed atmosphere bodies use the atmosphere field's gas identity to select clean or sooty optical response.
- Reconstructed liquid bodies use a liquid optical-family plane alongside connected liquid density.
- Shared appearance profiles provide class and phase inputs for WebGL and selected Canvas responses.
- Settled Smooth earth powders have a broad body treatment; Local and Grains remain alternative presentation styles.
- Saturated sponge has a deeper absorbed-light response in the compact 8× compositor.

The current capture and review commands are documented in [README.md](../README.md).
