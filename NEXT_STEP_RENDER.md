# Visual design target

The visual-overhaul target was **physically inspired stylized realism**: soft directional lighting, HDR emission, continuous fluid surfaces, and depth through absorption and scatter.

The scoped roadmap covered four areas:

1. HDR lighting, blackbody emission, bloom, and tonemapping.
2. Connected liquid surfaces and volumetric gas presentation.
3. Distinct material responses, including roughness, transmission, and broad body depth.
4. Presentation performance and optional WebGPU exploration.

The 2026-08-17 audit recorded this scope as implemented and visually reviewed in the canonical WebGL/HDR renderer. See [NEXT_STEP_RENDER_PROGRESS.md](NEXT_STEP_RENDER_PROGRESS.md) for the checkpoint summary. The original proposal and sequencing remain available in Git history.
