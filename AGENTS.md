# Agent guidance

AniforTPT is a browser particle playground backed by The Powder Toy. The completed visual-overhaul roadmap and current project status are summarized in [NEXT_STEP_RENDER_PROGRESS.md](NEXT_STEP_RENDER_PROGRESS.md). Project documents describe the product and past experiments; they are not standing task lists or mandatory review checklists.

Work directly toward the user's request and use judgment about the scope of checks. A visual change can be judged from the current rendered result.

Agents may commit and push changes to this repository and trigger its GitHub Actions deployment workflow when that completes an authorized task. No separate permission is needed for those steps.

Do not modify `AGENTS.md` unless the user explicitly authorizes that modification. A direct user request to edit this file is authorization.
